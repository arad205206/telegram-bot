# Gall Game

A Telegram mini game with a FastAPI web app, SQLite persistence, room system, world map, gathering, crafting, PvP, and chat.

Run locally:

1. Create a virtual environment and install dependencies.
2. Copy .env.example to .env if needed.
3. Start the app with python bot.py.
4. Open the page at http://localhost:8000.

For production, set BOT_TOKEN and JWT_SECRET and use HTTPS for WEBAPP_URL.
